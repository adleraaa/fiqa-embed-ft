# fiqa-embed-ft

Fine-tuning a 33M-parameter embedding model (BAAI/bge-small-en-v1.5) for financial
question answering retrieval on FiQA-2018 (BEIR), on one 8 GB laptop GPU.
Compares in-batch negatives, BM25 hard negatives and dense hard negatives with
false-negative filtering.

Experiments are in progress; results will be added from `results/`.
